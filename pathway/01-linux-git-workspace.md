# Stage 01 — Linux, Git & ROS Workspace

## Goal

Prepare the laptop so every later stage uses the same stable environment.

At the end of this stage you should be able to:

- use the Linux terminal comfortably;
- install packages with `apt`;
- understand file permissions and serial devices;
- clone, commit, branch and push with Git;
- install ROS 2 Jazzy on Ubuntu 24.04;
- create and build a ROS 2 workspace.

Do **not** start robot code until this setup is clean.

---

## 1. Use Ubuntu 24.04 LTS

Recommended setup order:

1. Native Ubuntu 24.04 install or dual boot — best option.
2. A dedicated Ubuntu laptop — also excellent.
3. Virtual machine — okay for early ROS learning, less convenient for graphics/USB hardware.
4. WSL — possible, but not the simplest route for a first physical ROS robot.

For this project, native Ubuntu is worth it because we need Gazebo graphics, USB serial access and ROS networking.

## 3. Install ROS 2 Jazzy

Target combination:

```text
Ubuntu 24.04
ROS 2 Jazzy Jalisco
Gazebo Harmonic
```

Follow the official installation instructions instead of copying random old commands:

- ROS 2 Jazzy Ubuntu install: https://docs.ros.org/en/jazzy/Installation/Ubuntu-Install-Debs.html
- ROS distributions/support: https://www.ros.org/reps/rep-2000.html

Install the **Desktop** variant because we need RViz and standard tools.

After installation:

```bash
source /opt/ros/jazzy/setup.bash
ros2 --help
printenv ROS_DISTRO
```

Expected:

```text
jazzy
```

Add the source command to your shell only after you understand what it does:

```bash
echo 'source /opt/ros/jazzy/setup.bash' >> ~/.bashrc
source ~/.bashrc
```

## 5. Create the ROS workspace

We will use:

```text
~/cleanbot_ws/
├── src/
├── build/
├── install/
└── log/
```

Create it:

```bash
mkdir -p ~/cleanbot_ws/src
cd ~/cleanbot_ws
colcon build
source install/setup.bash
```

The `src/` directory contains source packages. `build/`, `install/` and `log/` are generated by `colcon`.

Do not commit generated workspace folders to Git.

Recommended `.gitignore` entries:

```gitignore
build/
install/
log/
__pycache__/
*.pyc
.vscode/
.DS_Store
```

## 6. Understand ROS environment sourcing

There are two layers:

```bash
source /opt/ros/jazzy/setup.bash
```

loads installed ROS packages.

```bash
source ~/cleanbot_ws/install/setup.bash
```

loads packages you built yourself.

Normally, after building:

```bash
cd ~/cleanbot_ws
colcon build --symlink-install
source install/setup.bash
```

`--symlink-install` is useful for Python/config/launch development because many file changes do not require full copying into `install/`.

## 7. USB serial preparation

Later the Pico will appear as a device such as:

```text
/dev/ttyACM0
```

Learn to inspect devices:

```bash
ls /dev/ttyACM*
ls /dev/ttyUSB*
dmesg | tail
```

If serial access is denied, your user commonly needs the `dialout` group:

```bash
sudo usermod -aG dialout $USER
```

Log out and back in after changing groups.

Do not solve permission problems by permanently running robot software as root.
